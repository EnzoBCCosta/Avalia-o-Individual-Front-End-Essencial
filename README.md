# 📁 Avaliação Front-End Essencial

Exercícios de HTML e CSS desenvolvidos como avaliação individual.

---

## 📂 Estrutura

```
avaliacao-html-css/
├── exercicio-01/   → Página de apresentação pessoal
├── exercicio-02/   → Card de produto
└── exercicio-03/   → Layout com Flexbox
```

---

## 🗂️ Exercícios

**Exercício 01 — Apresentação Pessoal**
Página com nome, descrição, hobbies, imagem e link para rede social.

**Exercício 02 — Card de Produto**
Card de loja virtual com imagem, nome, descrição, preço e botão de compra.

**Exercício 03 — Layout Flexbox**
Reprodução de um layout utilizando Flexbox.

---

## 🛠️ Tecnologias

- HTML5
- CSS3
